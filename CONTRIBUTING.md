# Contributing documentation improvements

Documentation corrections and practical Java Edition NBT workflow suggestions are welcome.

## Good contributions

- Correcting a file path or version-specific detail.
- Adding a reproducible recovery or backup step.
- Improving explanations for server administrators and map makers.
- Reporting a broken link or unclear instruction.

## Please avoid

- Uploading private world or player files.
- Publishing server credentials, tokens, or personal data.
- Adding instructions that encourage editing a server you do not administer.
- Copying another project's documentation without permission and attribution.

Open an issue first for a larger documentation proposal, or submit a focused pull request for a small correction.
